dotfiles in purpose of hyprland wm ricing

hyprland rice — hypr, waybar, rofi, swaync, kitty, cava, btop, fastfetch, with matugen-generated colors across everything.

dependencies:
```
yay -S --needed hyprland xorg-xwayland xdg-desktop-portal-hyprland hyprpolkitagent hyprlock hyprcursor waybar rofi swaync awww-git kitty google-chrome thunar pavucontrol discord elecwhat wireplumber brightnessctl playerctl opentabletdriver networkmanager grim slurp libnotify psmisc procps-ng capitaine-cursors stow
```

## install

```
git clone https://github.com/chokorimu/hyprland-dotfiles.git ~/hypr-dotfiles
cd ~/hypr-dotfiles
./install.sh
```

`install.sh` deploys the packages with [GNU Stow](https://www.gnu.org/software/stow/) — every top-level directory mirrors `$HOME`, so `hypr/.config/hypr/` lands at `~/.config/hypr/`. Existing files that conflict are moved to `~/.dotfiles-backup-<timestamp>/` first. Re-run it any time to refresh the symlinks, or pass package names to deploy selectively (`./install.sh hypr waybar`).

## layout

| package | what |
|---|---|
| `hypr` | hyprland config (lua: `hyprland` / `animations` / `effects` / `keybinds`) + hyprlock |
| `waybar` | bar config + scripts (cava, mediaplayer, osu-status, blur toggle) |
| `rofi` | launcher, power menu, wallpaper menu, wallpapers (not tracked) |
| `kitty` | terminal |
| `cava` | visualizer + custom shaders/themes |
| `swaync` | notifications |
| `btop` / `fastfetch` | system monitor / fetch |
| `matugen` | color templates wired into hypr, rofi, waybar, kitty, cava |
| `bash` / `zsh` | shell rc files |
| `OpenTabletDriver` | tablet preset |

## keybinds

mainMod = `SUPER`

| key | action |
|---|---|
| `SUPER + Return` | kitty |
| `SUPER + B` | google-chrome-stable |
| `SUPER + E` | thunar |
| `SUPER + W` | close window |
| `SUPER + F` | fullscreen |
| `SUPER + V` | toggle float |
| `SUPER + P` | pseudo-tile |
| `SUPER + SHIFT + M` | exit hyprland |
| `SUPER + R` | restart waybar |
| `SUPER + D` | rofi drun launcher |
| `SUPER + G` | wallpaper menu |
| `SUPER + L` | power menu |
| `SUPER + arrows` | move focus |
| `SUPER + SHIFT + arrows` | move window |
| `SUPER + 1..0` | switch workspace |
| `SUPER + SHIFT + 1..0` | move window to workspace |
| `SUPER + S` / `SUPER + SHIFT + S` | toggle / send to special workspace |
| `SUPER + scroll` | cycle workspaces |
| `SUPER + LMB` / `RMB` drag | move / resize window |
| `Print` / `SHIFT + Print` | screenshot / area screenshot |
| `XF86` audio + brightness keys | volume, mute, brightness, media |

## theming

colors are generated by [matugen](https://github.com/InioX/matugen) from the current wallpaper — templates live in `matugen/.config/matugen/templates/` and write into hypr, rofi, waybar, kitty and cava. pick a wallpaper with `SUPER + G` and everything recolors.

## notes

- wallpapers are personal and not tracked by git — drop yours into `~/.config/rofi/wallpapers/`
- the repo assumes arch + an nvidia laptop in places (env vars, monitor mode, mouse device entry) — adjust `hypr/.config/hypr/` for other hardware
